# SubTrack

SubTrack is a command-line application for managing recurring subscriptions such as streaming services, software, gym memberships, and other services. Users can add, view, search, update, and delete subscriptions while tracking estimated monthly and yearly subscription expenses. Subscription data will be saved persistently between program sessions.

## Installation

Download the above folder.

## How to Run

Navigate to the folder location, and run "ruby subtrack.rb" in your terminal.
