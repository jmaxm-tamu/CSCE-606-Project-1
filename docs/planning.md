## Planning Discussion Documentation

### App:
SubTrack, a subscription tracking and management app

### Essential features: 
- Adding, deleting and listing subscriptions
- Storing subscription list persistently between sessions
- Showing monthly and yearly subscription costs

### Optional features:
- Filter subscriptions by category/search for individual named subscription
- Displaying subscriptions renewing within given period
- Sorting subscriptions based on name, cost, category, or next billing date
- Displaying cost for a given category

### Collaboration: 
The team will mainly collaborate individually and asynchronously, communicating on Discord or Canvas as needed. A pair programming session will be scheduled to gain experience in that regard.

### Completion: 
The core of the project will be “done” when the system can handle adding, deleting, and listing subscriptions, saving and loading subscription list data, and displaying monthly and yearly subscription costs.
